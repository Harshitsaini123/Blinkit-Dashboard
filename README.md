This project is a Power BI dashboard based on Blinkit sales and delivery data. The main goal of this project is to understand sales performance, customer behavior, product performance, and delivery operations through interactive visualizations.

I worked on the dataset by cleaning and preparing the data before using it in Power BI. The dashboard includes important KPIs and charts to make the data easier to understand and help identify useful business insights.

Key Areas Covered
Total Sales and Orders
Product and Category Performance
Customer Analysis
Delivery Time and Delivery Status
Outlet and Location Analysis
Payment Method Analysis
Sales Trends and Performance

Tools Used
Python
Pandas
Numpy
MySQL
Power BI
Excel/CSV
